Créer le compte administrateur

À faire une seule fois. Ensuite, la connexion se fera uniquement avec l'e-mail et le mot de passe.

Comment obtenir la clé d'accès GitHub ?
  1. Sur GitHub, ouvrez Settings → Developer settings → Fine-grained tokens.
  2. Nom : « Admin site EXAD ». Expiration : 1 an.
  3. Repository access : « Only select repositories » → exadwebsite.
  4. Permissions : Contents → Read and write, et Actions → Read-only.
  5. Cliquez sur « Generate token », copiez la clé et collez-la ici.
